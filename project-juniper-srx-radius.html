RADIUS Authentication on Juniper SRX

01

Project Overview

RADIUS-based authentication for remote Juniper SRX access, with Cisco ISE as the centralized RADIUS server.

02

Context / Challenge

After the Juniper SRX migration, remote access to the Juniper SRX devices was set up to use centralized RADIUS-based authentication.

03

My Role

Network Engineer. I configured the RADIUS authentication on the Juniper SRX devices.

04

Approach

Juniper SRX as RADIUS client → Cisco ISE as centralized RADIUS server → RADIUS-based authentication for SRX access → validation of connectivity and authentication

05

Implementation

The Juniper SRX devices act as RADIUS clients and Cisco ISE acts as the centralized RADIUS server. Users authenticate through RADIUS to access the SRX. Connectivity and authentication were validated.

06

Technologies / Tools

Juniper SRXCisco ISERADIUS

07

Outcome / Result

RADIUS-based authentication is used for Juniper SRX access, with connectivity and authentication validated.

08

Relevant Notes

  • Customer details are anonymized.
  • No RADIUS secrets, hostnames or addresses are shown.
  • Separate from the Edge Router Replacement and the branch LAN 802.1X projects.
