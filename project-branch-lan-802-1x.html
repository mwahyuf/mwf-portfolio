Branch LAN 802.1X / RADIUS Access Control

01

Project Overview

802.1X access control on branch office MikroTik switches, so end-user devices must be registered before using the branch LAN.

02

Context / Challenge

Branch offices needed control over which end-user devices could access the branch LAN.

03

My Role

Network Engineer. I implemented DOT1X on the branch office switches.

04

Approach

DOT1X on branch MikroTik switches → branch switches as authenticators → MikroTik RADIUS server at headquarters for centralized authentication → device MAC addresses registered at the RADIUS server

05

Implementation

DOT1X was implemented on MikroTik switches at the branch offices. The branch switches act as authenticators, and a MikroTik RADIUS server at headquarters provides centralized authentication. New end-user devices must have their device MAC address registered or authorized at the headquarters RADIUS server to access the LAN.

06

Technologies / Tools

802.1X / DOT1XMikroTik switchesMikroTik RADIUS server

07

Outcome / Result

Only registered end-user devices receive access to the branch LAN.

08

Relevant Notes

  • Customer details are anonymized.
  • Separate from the Juniper SRX RADIUS authentication, which uses Cisco ISE.
